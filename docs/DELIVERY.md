# CareerCanvas Delivery

1. **Public repository:** [danial-maqbool/CareerCanvas](https://github.com/danial-maqbool/CareerCanvas).
2. **Local directory:** `D:\1 - Personal\Docs\Danial\Masters\MS AI\3rd Sem\Side Projects\Resume Builder`.
3. **Stack:** React 19, TypeScript, Vite, Tailwind CSS, dnd-kit, Zustand, React Hook Form, Zod, TipTap, Recharts, Lucide; Python 3.12 (3.11+ required), FastAPI, Pydantic v2, SQLAlchemy, Alembic, SQLite, Playwright/Chromium, pypdf, python-docx; pytest, Vitest, Playwright tests.
4. **Architecture:** Local API serves the built SPA; reusable profile items feed independent resume snapshots. Relational records connect document versions and career activity. Ten migrations preserve existing databases. Resume-file parsing is bounded and in-memory; approved import uses existing Career Profile validation. See [architecture](ARCHITECTURE.md).
5. **Features:** 80 documented capability groups, with explicit counting boundaries in [FEATURES.md](FEATURES.md).
6. **Templates:** 12: Classic, Modern, Minimal, Professional, Technical, Executive, Compact, Academic, Creative, Two Column, Developer, Research.
7. **Editing:** Three panels, inline text, rich summary, local content customization, visibility, custom sections, naming, independent duplication, archive/delete, autosave, undo/redo, versions/diffs/restore.
8. **Drag and drop:** Sections, experience bullets, Kanban cards, and dashboard widgets; keyboard alternatives for editor order and dashboard controls, plus application stage selection.
9. **Styling:** Six system-font options, type size, line height, margins, section/bullet spacing, colors/presets, headings, alignment, dates, skill columns/separators, A4/Letter, zoom, fit, and overflow guidance.
10. **PDF:** Implemented selectable-text Chromium export with links, measured pagination, and oversized-content safeguards.
11. **DOCX:** Implemented editable semantic Word export with headings, bullets, links, basic styling, and page settings.
12. **ATS:** Eleven weighted CareerCanvas checks plus direct PDF/DOCX/TXT uploaded-file review. Direct review reports extractable text, standard sections, reading-order risk, image-only risk, contact information, text density, page count where available, structure, links, and extracted text. Scores remain application-specific, not employer scoring. See [ATS analysis](ATS_ANALYSIS.md).
13. **Resume import:** PDF, DOCX, and TXT can be parsed locally into reviewed Career Profile proposals with confidence, source evidence, and explicit duplicate actions. Direct ATS results can reuse the same upload for Career Profile import or creation of an independent editable CareerCanvas resume. See [resume import](RESUME_IMPORT.md).
14. **Job match:** Skill/keyword/experience/education/role components, explicit gaps and related evidence, existing profile suggestions, approved independent tailored copies.
15. **AI:** Optional Gemini/Ollama rewrite adapters, consent boundary, original/suggested review, and factual-change flags. Live providers are unverified without configuration; factual checks are heuristics. Resume-file import does not require AI.
16. **AI-disabled mode:** Core editor, imports, direct file ATS, exports, versions, libraries, ATS, matching, jobs, interviews, and analytics operate with AI off.
17. **Career Profile:** Personal details, experience, education, skills, projects, certifications, publications, achievements, languages, references, portfolio, completion guidance, and reviewed resume import.
18. **Jobs:** Ten-stage Kanban, details, document associations, timeline, contacts, tasks, follow-ups, notes, tags, and deadlines. Immediate reopen uses the revision returned by save.
19. **Interviews:** Scheduling, logistics, rounds, interviewers, seven-step preparation, linked STAR stories, and categorized questions.
20. **Analytics:** Submissions, response/interview/offer rates, average response time, sources, roles, months, funnel, and observed outcomes per resume. No causation claim.
21. **Demo:** Fictional Alex Morgan; 26 profile items, four resumes with versions, twelve applications, three interviews, three goals, one letter/contact/STAR story, three questions, five tags.
22. **Original Windows acceptance:** 93 backend and 17 frontend tests passed; TypeScript/Vite production build passed. Resume-import regression coverage is added to the current automated suite.
23. **Playwright:** Original 33-workflow result is recorded in [VALIDATION.md](VALIDATION.md). A dedicated resume-import/direct-ATS browser journey is now included in `frontend/tests/resume-import.spec.ts` and the GitHub Actions workflow.
24. **PDF validation:** Twelve templates plus ten A4/Letter layout cases and overflow rejection. Twenty-four template pages reviewed, zero out-of-page glyphs; text and links inspected programmatically.
25. **DOCX validation:** All template inputs, hidden content, rich text, and letter content inspected; complete-profile sample rendered read-only in Microsoft Word and visually reviewed across three pages. DOCX resume **import** is separate and extracts paragraphs, tables, and hyperlinks.
26. **Responsive validation:** 1920x1080, 1440x900, 1366x768, 1024x768, 768x1024, and 390x844 browser viewports passed the original acceptance suite. Physical devices are not certified.
27. **Limitations:** Local single-user deployment; English heuristic analysis; incomplete AI factual detection; live providers unverified; DOCX export is a single-column reconstruction; automatic OCR for scanned/image-only resume imports is not bundled; optional photo support is absent; very large indivisible text needs manual restructuring.
28. **Known bugs:** No unresolved failures are claimed until the current GitHub Actions extension validation is green. Upstream dependency deprecation/build warnings remain documented.
